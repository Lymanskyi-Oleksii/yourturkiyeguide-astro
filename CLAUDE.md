# Інструкції для Claude Code

## Проєкт
Сайт гіда по Туреччині на Astro 7. Статичний, відгуки зберігаються у Firebase Firestore,
бронювання через WhatsApp. План виправлень — docs/PLAN.md.

## Як працюємо
- Виконуй ЛИШЕ той пункт плану, який я назву (наприклад «пункт 1.4»). Нічого понад це.
- Перед змінами коротко опиши, що саме зміниш і в яких файлах.
- Якщо помітив інші проблеми — напиши про них, але не виправляй без дозволу.
- Не роби git commit і git push, доки я не попрошу.
- Після змін запусти `npm run build` і переконайся, що збирання проходить.
- Наприкінці напиши, як мені перевірити результат у браузері.

## Домовленості в коді
- Мова інтерфейсу сайту — російська. Коментарі в коді — українською.
- Не додавай нових залежностей у package.json без мого дозволу.
- Номер телефону, email і посилання на месенджери не змінюй.
- Ключ Firebase у src/scripts/firebase-init.js публічний за задумом — не прибирай його.
- Стилі й скрипти — у src/styles і src/scripts, не в public/. Порядок CSS важливий:
  кілька файлів для сторінки підключай через збірку в src/styles/*.css (@import).
- Властивість із префіксом пиши перед стандартною (-webkit-backdrop-filter, потім
  backdrop-filter), інакше мініфікатор викине стандартну.
- Тури — файли src/content/tours/*.md, контакти — src/data/site.ts. Будова проєкту — у README.md.

## Відмітки в плані
- Після завершення пункту познач його в docs/PLAN.md: у зведеній таблиці
  додай колонку «Статус» (якщо її ще немає) і постав ✅ та дату, а в заголовку
  самого пункту допиши « — ✅ виконано (дата)».
- Не позначай пункт виконаним, доки npm run build не пройшов.
- Якщо пункт зроблено частково, пиши «🟡 частково» і що саме лишилося.
